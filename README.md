This is my project for the first Full Stack assignment. I created a "Vector Vault" system wherein you could register a new account and log in to view the list of other members' accounts. As for the design, I applied the concept of "glassmorphism" style in the dashboard and registry pages via Tailwind CSS to make it look neater. To use this project, all you have to do is install Apache and MySQL via XAMPP, create a database with the name "user_system" via phpMyAdmin, and import the provided "user_system.sql" file in the folder. After moving the folder to the 'htdocs' folder in the XAMPP directory, you could just open "localhost/FullStack_Project_Catipon/index.php." I made my database username 'root' with no password since it would be used in the local environment and would not require any alterations in the codes.
